Voleibol de playa: qué hace ganar a una pareja

Capítulo 5 Limpieza y preparación

La limpieza se hace una sola vez, con el código de este capítulo, que aplica los pasos de abajo sobre el archivo original y escribe tres archivos limpios en la carpeta datos_limpios/. La versión en Python repite los mismos pasos y debe obtener las mismas cifras de control. Este capítulo resume qué se encontró y qué se decidió; ninguna fila se elimina por calidad salvo las que son lógicamente imposibles.

Duplicados y llave del partido

df <- raw

n_orig        <- nrow(df)
n_dup_exactas <- nrow(df) - nrow(dplyr::distinct(df))
n_llave_rep   <- sum(duplicated(df[c("tournament", "year", "gender", "match_num")]))

# Un torneo puede tener más de un evento en el mismo año (por ejemplo, un torneo
# reprogramado). Se separan en eventos nuevos si hay más de 14 días entre partidos.
eventos <- df %>%
  distinct(circuit, tournament, year, date) %>%
  arrange(circuit, tournament, year, date) %>%
  group_by(circuit, tournament, year) %>%
  mutate(evento = 1L + cumsum(c(FALSE, diff(date) > 14))) %>%
  ungroup()

n_torneos_multi <- eventos %>%
  group_by(circuit, tournament, year) %>%
  summarise(k = max(evento)) %>%
  filter(k > 1) %>%
  nrow()

df <- df %>% left_join(eventos, by = c("circuit", "tournament", "year", "date"))

# Partidos con el mismo jugador en las dos parejas: son imposibles
mismo_jugador <- tidyr::replace_na(
  df$w_player1 == df$l_player1 | df$w_player1 == df$l_player2 |
  df$w_player2 == df$l_player1 | df$w_player2 == df$l_player2, FALSE)
n_mismo <- sum(mismo_jugador)
df <- df[!mismo_jugador, ]

El faltante más grande, y el que más condiciona el libro, son las estadísticas de juego. No faltan al azar: dependen del circuito. En w_p1_tot_kills falta el 97,3 % de los partidos de la FIVB frente al 48,0 % de los de la AVP. Es decir, el faltante se explica por una variable que sí conocemos (circuit): un mecanismo de datos faltantes dependiente de lo observado, no completamente aleatorio (Rubin 1976). En consecuencia, cualquier resultado con estadísticas de juego describe casi solo a la AVP y no se generaliza al deporte completo.

El ranking tiene un faltante alto porque, en los puestos de clasificatoria ("Q16"), no hay ranking principal que inferir; inventarlo sería fabricar información. Por eso los análisis con ranking cubren solo los partidos en los que ambas parejas tienen ranking numérico, y se dice explícitamente cuántos son.

Correcciones de calidad

# 1. Ranking: separar el número de la marca de clasificatoria ("17, Q2" -> 17 y "Q2")
sep_rank <- function(x) {
  x <- trimws(as.character(x))
  list(num  = rank_num(x),
       qual = ifelse(grepl("Q", x), sub("^.*?(Q[0-9]+).*$", "\\1", x, perl = TRUE),
                     NA_character_))
}
r <- sep_rank(df$w_rank); df$w_rank_num <- r$num; df$w_rank_qual <- r$qual
r <- sep_rank(df$l_rank); df$l_rank_num <- r$num; df$l_rank_qual <- r$qual

# 2. Fechas de nacimiento con el siglo equivocado (2068 en lugar de 1968)
corregir_fecha <- function(b, f) {
  mal <- !is.na(b) & !is.na(f) & b > f
  y <- as.integer(format(b[mal], "%Y")) - 100L
  b[mal] <- as.Date(paste0(y, format(b[mal], "-%m-%d")))
  b
}
n_bd_corr <- 0
for (p in c("w_p1", "w_p2", "l_p1", "l_p2")) {
  col <- paste0(p, "_birthdate")
  n_bd_corr <- n_bd_corr + sum(df[[col]] > df$date, na.rm = TRUE)
  df[[col]] <- corregir_fecha(df[[col]], df$date)
}
# Comprobación: la edad calculada con la fecha corregida debe coincidir con `age`

Dos comprobaciones importantes. Primero, tras corregir las fechas de nacimiento, la edad calculada coincide con la columna age (diferencia menor a un año en el 100,0 % de las filas), lo que confirma que el error estaba en el siglo y no en el resto de la fecha. Formato largo y archivos limpios

El análisis compara parejas ganadoras con perdedoras, así que conviene tener una fila por pareja y partido (dos filas por partido) en lugar de columnas w_ y l_.

lado <- function(p) {
  df %>% transmute(match_id, circuit, tournament, year, date, gender, etapa,
                   jugador1 = .data[[paste0(p, "_player1")]],
                   jugador2 = .data[[paste0(p, "_player2")]],
                   rank_num = .data[[paste0(p, "_rank_num")]],
                   edad     = .data[[paste0(p, "_age")]],
                   estatura = .data[[paste0(p, "_hgt")]])
}

parejas <- bind_rows(mutate(lado("w"), resultado = "ganadora", gano = 1L),
                     mutate(lado("l"), resultado = "perdedora", gano = 0L)) %>%
  mutate(resultado = factor(resultado, levels = c("ganadora", "perdedora"))) %>%
  arrange(match_id, desc(gano))

jug <- function(pre, resultado, pos) {
  p <- paste0(pre, "_p", pos)
  df %>% transmute(match_id, circuit, year, gender, resultado = resultado, posicion = pos,
                   jugador    = .data[[paste0(pre, "_player", pos)]],
                   pais       = .data[[paste0(p, "_country")]],
                   nacimiento = .data[[paste0(p, "_birthdate")]],
                   edad       = .data[[paste0(p, "_age")]],
                   estatura   = .data[[paste0(p, "_hgt")]])
}
jugadores <- bind_rows(jug("w", "ganadora", 1), jug("w", "ganadora", 2),
                       jug("l", "perdedora", 1), jug("l", "perdedora", 2)) %>%
  arrange(match_id, resultado, posicion)
